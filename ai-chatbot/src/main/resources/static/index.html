👋 Welcome to the AI Assistant!

This project is organized following clean MVC patterns: Model / Entity • DTO • Service • Controller • View.

Available Features:

  • 🌤️ Live Weather: Real-time 3rd-party weather (WeatherAPI.com with Open-Meteo fallback) persisted into H2 JPA Database.
  • 💬 AI Tool Integration: In chat mode, ask "What's the weather in Tokyo?" and the AI automatically fetches real-time data!
  • 🧠 Document RAG: Semantic similarity search over PDFs using 100% free offline local embeddings.
  • 📄 Instant PDF Summarization: Executive structured breakdowns in seconds.
